# 🚀 QuickJournal

AI-powered Reflective Journal Generator for Students

---

## 📌 Overview

QuickJournal helps students generate reflective journals instantly.

Instead of writing manually, students can:
- Select subject & module
- Generate journal
- Download PDF

---

## ✨ Features

- AI-generated human-like journals
- Structured format (Experience, Feelings, Learning, Application, Conclusion)
- Automatic PDF generation
- Fast and easy to use

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js (Express)
- AI: Google Gemini API
- PDF: jsPDF
